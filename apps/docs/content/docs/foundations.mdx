# Foundations

Design tokens extracted from the [Figma identity file](https://www.figma.com/design/6oh9nv9KYdFOTXAQ6oVuFw).

## Colors

| Token | Value | Usage |
|-------|-------|-------|
| Lilac | `#B97CFF` | Primary CTA |
| Brand Blue | `#2F77EE` | Links, accent |
| Violet | `#7829D2` | Secondary text |
| Success | `#5FCA89` | Success states |
| Footer | `#061E47` | Dark footer bg |
| Surface | `#ECEFF1` | Page background |

Primary button states: default `#B97CFF` → hover `#A357FB` → active `#9132FF`.

## Typography

Font families: **IBM Plex Sans** (UI), **IBM Plex Serif** (accent headings).

Responsive heading utilities: `text-h1`, `text-h2`, `text-h3`, `text-h4`, `text-h1-serif`, `text-h3-serif`.

Body utilities: `text-body-14` through `text-body-32-medium`.

## Radius

Default border radius: **10px** (`rounded-[10px]`).
