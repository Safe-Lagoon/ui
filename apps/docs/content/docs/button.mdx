# Button

Brandbook button with lilac primary CTA, secondary lilac/blue outlines, and tertiary link style.

## Usage

- `primary` — Lilac fill (default CTA)
- `primary-long` — Wide lilac button
- `secondary-lilac` — Lilac outline
- `secondary-blue` — Blue outline
- `tertiary` — Text link style

## Usage

```tsx
import { Button } from "@safelagoon/ui";

<Button variant="primary">Get started</Button>
<Button variant="secondary-blue" size="sm">Learn more</Button>
```
