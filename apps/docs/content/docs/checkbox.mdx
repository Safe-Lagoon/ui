# Checkbox

Radix-based checkbox with Safe Lagoon brand styling — lilac fill when checked, focus ring, and disabled states.

## Usage

```tsx
import { Checkbox } from "@safelagoon/ui";

<Checkbox id="terms" />
<label htmlFor="terms">Accept terms</label>
```
